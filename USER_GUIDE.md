# Prayer Time Notification App - User Guide

## Overview
The Prayer Time Notification App provides accurate prayer times for cities in Morocco and sends notifications before each prayer time. This guide will help you understand how to use the app effectively.

## Installation
1. Download the APK file from the provided location
2. Enable installation from unknown sources in your device settings:
   - Go to Settings > Security > Unknown Sources (or Settings > Apps > Special access > Install unknown apps)
   - Enable the option to allow installation from this source
3. Install the APK file by tapping on it and following the on-screen instructions
4. Open the app after installation is complete

## First-Time Setup
When you first open the app, you'll need to:
1. Select your city from the list of Moroccan cities
2. Grant notification permissions when prompted
3. Configure notification settings (optional)

## Main Features

### Viewing Prayer Times
- The main screen displays today's prayer times for your selected city
- Each prayer card shows:
  - Prayer name
  - Prayer time
  - Time remaining until the prayer
- Pull down to refresh and get the latest prayer times

### Changing City
- Tap on the city name at the top of the main screen
- Select a new city from the list
- The prayer times will automatically update for the selected city

### Notification Settings
Access notification settings by tapping the settings icon in the top-right corner:
- Enable/disable all notifications
- Set individual prayer notifications on/off
- Choose how many minutes before prayer to receive notifications
- Select notification sound

### Offline Support
- The app caches prayer times for your selected city
- You can view prayer times even without an internet connection
- The app will automatically update cached data when an internet connection is available

## Troubleshooting

### Notifications Not Working
1. Check if notifications are enabled in the app settings
2. Verify that the app has notification permissions in your device settings
3. Make sure battery optimization is disabled for the app
4. Restart the app or your device

### Prayer Times Not Updating
1. Check your internet connection
2. Pull down to refresh on the main screen
3. Try selecting your city again
4. Restart the app

### App Crashes or Freezes
1. Ensure you have the latest version of the app
2. Restart your device
3. Reinstall the app if problems persist
